Use

import primlib
# appended to the document's Params sheet under "Latch: Latch",
# aliases Latch_height, Latch_arms, ...
obj = primlib.make("latch", doc, "Latch")
obj = primlib.make("latch", doc, "Latch", height='52', arms='2')   # starting values

# into another sheet, or with plain shared aliases (height, ...)
obj = primlib.make("latch", doc, "Latch", sheet=sheet)
obj = primlib.make("latch", doc, "Latch", prefix="")

# or drive params from expressions you already have
obj = primlib.make("latch", doc, "Latch", sheet=sheet,
                 bind={"height": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Latch. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, the hidden helper objects described above, and the result <name>, tagged PrimlibPrimitive = "latch". They are plain FreeCAD objects: the saved file does not need primlib.
