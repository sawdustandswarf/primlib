Plate

primlib/primitives/plate.py · class Plate · all primitives

Deprecated: part of the old ring hinge (hinge_deprecated), used only by latch. Don't use it for new work; it goes when the latch moves to hinge.

A rectangular plate length (x) by width (y) by thickness (z), its corner at the origin, with a grid of screws_x by screws_y screw holes. The holes are spread evenly between the edge margins: the outer hole centres sit edge_margin in from each edge, and a count of 1 centres the holes in that direction.

The holes are the screw hole primitive -- hole_type 0 none, 1 plain, 2 countersunk, 3 counterbored, heads at the top face -- with the same parameters, so a sheet edit switches the hole type, counts or sizes. Built as a box minus a Draft array of one hole tool; the array is moved clear of the plate when hole_type is 0.

Use

import primlib
# appended to the document's Params sheet under "Plate: Plate",
# aliases Plate_length, Plate_width, ...
obj = primlib.make("plate", doc, "Plate")
obj = primlib.make("plate", doc, "Plate", length='40', width='20')   # starting values

# into another sheet, or with plain shared aliases (length, ...)
obj = primlib.make("plate", doc, "Plate", sheet=sheet)
obj = primlib.make("plate", doc, "Plate", prefix="")

# or drive params from expressions you already have
obj = primlib.make("plate", doc, "Plate", sheet=sheet,
                 bind={"length": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Plate. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, the hidden helper objects described above, and the result <name>, tagged PrimlibPrimitive = "plate". They are plain FreeCAD objects: the saved file does not need primlib.
