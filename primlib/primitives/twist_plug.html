Twist plug

primlib/primitives/twist_plug.py · class TwistPlug · all primitives

The male half of a twist lock, built locked in a twist_socket with the same parameters at the same origin: a flange body_d across and flange_t thick on the socket's face (z = 0 to flange_t), a shaft tol inside the mouth down to tol off the floor, and lugs lugs, each lug_angle of arc from 0 deg anticlockwise (then every 360 / lugs), whose upper flank is the socket's flank raised preload, rounded radius at the root and radius - tol at the tip. Each lug's leading end (at 0 deg: the plug turns clockwise to lock) is lowered lead, running out over lead_angle (a smooth loft through a few sections; its angles are fixed when the plug is built). The flange's underside has a dimple over each detent bump, tol over.

mouth_d is the mouth's sharp diameter (the lip's sharp inner edge, no rounds), not what calipers read, unlike rail15 and topeak_rail, so check a print against it with care.

To fit it, turn the plug twist anticlockwise of this, drop it in and turn it clockwise twist.

Use

import primlib
# appended to the document's Params sheet under "TwistPlug: Twist plug",
# aliases TwistPlug_mouth_d, TwistPlug_depth, ...
obj = primlib.make("twist_plug", doc, "TwistPlug")
obj = primlib.make("twist_plug", doc, "TwistPlug", mouth_d='30', depth='3.5')   # starting values

# into another sheet, or with plain shared aliases (mouth_d, ...)
obj = primlib.make("twist_plug", doc, "TwistPlug", sheet=sheet)
obj = primlib.make("twist_plug", doc, "TwistPlug", prefix="")

# or drive params from expressions you already have
obj = primlib.make("twist_plug", doc, "TwistPlug", sheet=sheet,
                 bind={"mouth_d": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Twist plug. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, the hidden helper objects described above, and the result <name>, tagged PrimlibPrimitive = "twist_plug". They are plain FreeCAD objects: the saved file does not need primlib.
