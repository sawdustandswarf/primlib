Panel

primlib/primitives/panel.py · class Panel · all primitives

A flat sheet length (x) by width (y), thickness (z) thick, its corner at the origin: a panel cut from plywood or other sheet, as the hybrid case's walls are. It isn't printed; an assembly turns it into place, so it is cut and listed lying flat.

Parameters

length300size along x
width200size along y

Use

import primlib
# appended to the document's Params sheet under "Panel: Panel",
# aliases Panel_length, Panel_width, ...
obj = primlib.make("panel", doc, "Panel")
obj = primlib.make("panel", doc, "Panel", length='300', width='200')   # starting values

# into another sheet, or with plain shared aliases (length, ...)
obj = primlib.make("panel", doc, "Panel", sheet=sheet)
obj = primlib.make("panel", doc, "Panel", prefix="")

# or drive params from expressions you already have
obj = primlib.make("panel", doc, "Panel", sheet=sheet,
                 bind={"length": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Panel. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, the hidden helper objects described above, and the result <name>, tagged PrimlibPrimitive = "panel". They are plain FreeCAD objects: the saved file does not need primlib.
