Screw hole

primlib/primitives/hole.py · class Hole · all primitives

Deprecated: part of the old ring hinge (hinge_deprecated), used only by latch. Don't use it for new work; it goes when the latch moves to hinge.

The cutting tool for one screw hole through a plate thickness thick, axis on z, plate bottom at z = 0 and the screw head at the top. hole_type picks the shape: 0 none, 1 plain, 2 countersunk, 3 counterbored. It is an ordinary spreadsheet cell -- change it and recompute; the profile keeps the same four wall points for every type and only their positions change.

Every face is grown by tolerance along its own normal: the shank radius by tolerance, the countersink cone so its flank stands tolerance off the head's (radius + tolerance / sin of the flank angle), the counterbore radius by tolerance and its floor tolerance deeper than head_height. The tool overshoots both plate faces by over so the cut is clean. Type 0 builds the plain shape; a plate moves its holes clear of the material instead.

Use

import primlib
# appended to the document's Params sheet under "Hole: Screw hole",
# aliases Hole_hole_type, Hole_thickness, ...
obj = primlib.make("hole", doc, "Hole")
obj = primlib.make("hole", doc, "Hole", hole_type='2', thickness='5')   # starting values

# into another sheet, or with plain shared aliases (hole_type, ...)
obj = primlib.make("hole", doc, "Hole", sheet=sheet)
obj = primlib.make("hole", doc, "Hole", prefix="")

# or drive params from expressions you already have
obj = primlib.make("hole", doc, "Hole", sheet=sheet,
                 bind={"hole_type": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Screw hole. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, a sketch <name>_sketch whose vertex i is held by constraints ri and zi, and the Part::Revolution <name>, tagged PrimlibPrimitive = "hole". They are plain FreeCAD objects: the saved file does not need primlib.
