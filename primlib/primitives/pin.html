Retained pin

primlib/primitives/pin.py · class Pin · all primitives

Deprecated: part of the old ring hinge (hinge_deprecated), used only by latch. Don't use it for new work; it goes when the latch moves to hinge.

A straight shaft of diameter diam capped at each end by a conical flare that opens out to diam_end, the flanks at angle to the end faces. A sleeve snapped over the shaft is trapped between the flares.

clearance grows every face along its own outward normal, giving the envelope the pin must clear in a bore. The grown flares keep the flank angle, so the flare diameter grows by 2c / tan(angle / 2), and the envelope stays centred on the nominal pin: it spans z = -c .. height + c.

Use

import primlib
# appended to the document's Params sheet under "Pin: Retained pin",
# aliases Pin_height, Pin_diam, ...
obj = primlib.make("pin", doc, "Pin")
obj = primlib.make("pin", doc, "Pin", height='10', diam='6')   # starting values

# into another sheet, or with plain shared aliases (height, ...)
obj = primlib.make("pin", doc, "Pin", sheet=sheet)
obj = primlib.make("pin", doc, "Pin", prefix="")

# or drive params from expressions you already have
obj = primlib.make("pin", doc, "Pin", sheet=sheet,
                 bind={"height": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Retained pin. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, a sketch <name>_sketch whose vertex i is held by constraints ri and zi, and the Part::Revolution <name>, tagged PrimlibPrimitive = "pin". They are plain FreeCAD objects: the saved file does not need primlib.
