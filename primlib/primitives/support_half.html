Half-cylinder support

primlib/primitives/support_half.py · class SupportHalf · all primitives

A print support under your own control for a round part: a half cylinder of radius on the +y side of the x axis, centred on the origin, from the face below at z = 0 to the face it holds up at z = height.

Concentric half-ring walls, each wall_lines lines wide with gap_lines lines between them, are laid in from the rim, and a wall along the flat side ties them together. They stand between two interface layers, one layer_h layer each. Each interface layer is radial: single-line spokes from the centre, as many as make interface_density of the rim (0.33: a line in every three), joined by a line round the rim and one along the flat side. Cut off at x = trim, it keeps a wall along the cut, and each interface layer a line, so the boundary stays closed. The top layer stops interface_gap under the supported face, and the bottom layer starts bottom_gap above z = 0 (0 on the bed), so the support breaks away after printing.

The spokes are a Draft polar array, so their number follows the sheet; the number of rings is fixed when the support is built (each ring is its own pair of cylinders), and rings that no longer fit shrink onto the innermost -- rebuild to lay them in again.

Use

import primlib
# appended to the document's Params sheet under "SupportHalf: Half-cylinder support",
# aliases SupportHalf_radius, SupportHalf_height, ...
obj = primlib.make("support_half", doc, "SupportHalf")
obj = primlib.make("support_half", doc, "SupportHalf", radius='5', height='3')   # starting values

# into another sheet, or with plain shared aliases (radius, ...)
obj = primlib.make("support_half", doc, "SupportHalf", sheet=sheet)
obj = primlib.make("support_half", doc, "SupportHalf", prefix="")

# or drive params from expressions you already have
obj = primlib.make("support_half", doc, "SupportHalf", sheet=sheet,
                 bind={"radius": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Half-cylinder support. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, the hidden helper objects described above, and the result <name>, tagged PrimlibPrimitive = "support_half". They are plain FreeCAD objects: the saved file does not need primlib.
