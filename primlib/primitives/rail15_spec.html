15 mm rail

Specification of rail15 and rail15_housing · rail page · housing page · all primitives

Four fixed parameters define the shape. The rail has no tolerance, and its width is 15.00 whatever the variable parameters are. All sizes are in mm.

2. The rail

3. Why the width is exactly 15.00

A radius tangent to the tip face and the flank has its centre t in from the sharp corner, along the tip face, set by half the 60° angle. Its vertical tangent is one radius outside its centre. So half the width is the sharp corner, less t, plus the radius. The primitive turns that round to get the sharp corner from 15:

t = tip_radius / tan(angle / 2) = 1 / tan 30° = 1.732051 tip_hw = width / 2 + t - tip_radius = 7.5 + 1.732051 - 1 = 8.232051 check, worked back from the sharp corner: 2 x (tip_hw - t + tip_radius) = 2 x (8.232051 - 1.732051 + 1) = 15.000000

Substituting, t and tip_radius cancel, leaving width. So it's exactly 15, and neither depth nor the root enters it. The primitive refuses to build if the check differs from 15 by a millionth of a mm, and the print test script measures the finished solid and stops if it isn't 15.000000.

4. The variable parameters, drawn

5. The clearance and the matching part

clearance (default 0.20) is the gap between the printed parts. It's normal to every face and per side, so a width across the slot grows by twice it. The slot is the rail grown by it. The tip's radius keeps its centre and grows to 1 + clearance. The mouth's lip keeps the root radius's centre, with radius 0.20 - clearance. That can't go below 0, so from 0.20 up the lip is a sharp corner.

6. Tapered ends

end_taper is an option on both parts, off by default: lead-ins, so the rail finds its way into the slot rather than catching on the end of it. It's the same size on both ends of a part. Over the last end_taper of the length, the rail's tapered part shrinks by end_taper normal to its faces, and the slot grows by it. The change is the same as the distance along x, so the lead-in is at 45°. The print test uses 0.5.

The rail's support doesn't change, nor does the housing's mating face. Between the lead-ins, both parts have exactly the profile shown above, so the width and the mouth are measured there. At the very end the rail's tip radius is 1 - end_taper and the slot's floor radius is 1 + clearance + end_taper, each concentric with the full radius, and the root radius and the lip stay as they are. So end_taper must be less than 1.

7. The printer width offset

This keeps the printer out of the fit. clearance is only ever the gap between the printed parts; whatever the printer does to a part's width is corrected separately, on that part. Every size in this document is the design size, what the print should measure.

width in the model = design width + printer_width_offset

Half goes to each side, across y only: each half of the section moves sideways, unchanged, so the depth, the angle and the radii stay exact, and only the flat tip face and flat floor get wider. Each part has its own value, because a printer needn't move a slot's walls as it moves a rail's. The block's outside doesn't change.

rail: printer_width_offset = 15.00 - (width measured at 0) housing: printer_width_offset = (design mouth, section 5) - (mouth measured at 0) examples, for illustration: rail measured 14.60 -> offset 0.40, model 15.40, should print 15.00 clearance 0.20, mouth measured 13.00 -> offset -0.46, model 12.08, should print 12.54

A negative offset is allowed. If the two offsets differ, the two models won't show the printed gap, and may even overlap as models. That's expected: it's the printed parts that have the clearance.
