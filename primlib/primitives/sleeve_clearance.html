Sleeve clearance

primlib/primitives/sleeve_clearance.py · class SleeveClearance · all primitives

Deprecated: part of the old ring hinge (hinge_deprecated), used only by latch. Don't use it for new work; it goes when the latch moves to hinge.

The clearance envelope of a sleeve, used as a cutting tool to make the pocket a sleeve turns in. Only the sleeve's outside counts: the outer wall and the 45-degree W flanks are each offset by clearance along their own normal, and the inside -- bore and pin -- is filled solid to the axis.

The flanks meet the offset ends in sharp corners (as the pin's clearance envelope does), so the gap is clearance normal to every face. The ends are flat, clearance beyond the sleeve's ridge rings; a stack of these overlaps its neighbours there, which is harmless for a pocket cut. Takes every sleeve parameter, so it stays in step with the sleeve it clears.

Use

import primlib
# appended to the document's Params sheet under "SleeveClearance: Sleeve clearance",
# aliases SleeveClearance_height, SleeveClearance_diam, ...
obj = primlib.make("sleeve_clearance", doc, "SleeveClearance")
obj = primlib.make("sleeve_clearance", doc, "SleeveClearance", height='10', diam='6')   # starting values

# into another sheet, or with plain shared aliases (height, ...)
obj = primlib.make("sleeve_clearance", doc, "SleeveClearance", sheet=sheet)
obj = primlib.make("sleeve_clearance", doc, "SleeveClearance", prefix="")

# or drive params from expressions you already have
obj = primlib.make("sleeve_clearance", doc, "SleeveClearance", sheet=sheet,
                 bind={"height": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Sleeve clearance. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, a sketch <name>_sketch whose vertex i is held by constraints ri and zi, and the Part::Revolution <name>, tagged PrimlibPrimitive = "sleeve_clearance". They are plain FreeCAD objects: the saved file does not need primlib.
