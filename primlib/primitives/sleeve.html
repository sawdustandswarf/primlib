Sleeve

primlib/primitives/sleeve.py · class Sleeve · all primitives

Deprecated: part of the old ring hinge (hinge_deprecated), used only by latch. Don't use it for new work; it goes when the latch moves to hinge.

A hollow barrel that wraps a retained pin with a uniform running clearance: the bore is the pin's clearance envelope, every pin face offset by tolerance along its own normal, so the gap measured normal to the faces is tolerance everywhere -- flanks and shaft alike.

Bore: the envelope's flank cones, at the pin's flank angle, open from the ridge ring down into the throat (diam / 2 + tolerance). A pin flare cannot pass the throat, which is what retains the sleeve on the pin.

Outside: a cylinder diam_outer whose ends are 45-degree W flanks rising from the ridge ring, where the bore flank meets the end face. Two stacked sleeves meet only along that ring.

end_gap shortens the sleeve by end_gap / 2 at each end, so sleeves stacked on pin segments of the same height stand end_gap apart at their ridge rings (needed for print-in-place). The bore is still the pin's envelope, so the ridge ring moves in to where that envelope crosses the shortened end face.

Use

import primlib
# appended to the document's Params sheet under "Sleeve: Sleeve",
# aliases Sleeve_height, Sleeve_diam, ...
obj = primlib.make("sleeve", doc, "Sleeve")
obj = primlib.make("sleeve", doc, "Sleeve", height='10', diam='6')   # starting values

# into another sheet, or with plain shared aliases (height, ...)
obj = primlib.make("sleeve", doc, "Sleeve", sheet=sheet)
obj = primlib.make("sleeve", doc, "Sleeve", prefix="")

# or drive params from expressions you already have
obj = primlib.make("sleeve", doc, "Sleeve", sheet=sheet,
                 bind={"height": "MyAlias * 2"})

In the FreeCAD GUI: the primlib workbench has a button for Sleeve. Its parameters are appended to the document's Params sheet under a title row, or to the selected spreadsheet if one is selected.

Objects created: the spreadsheet rows, a sketch <name>_sketch whose vertex i is held by constraints ri and zi, and the Part::Revolution <name>, tagged PrimlibPrimitive = "sleeve". They are plain FreeCAD objects: the saved file does not need primlib.
