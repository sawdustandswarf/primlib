Retained pin

The retained pin is a cylindrical shaft with a splayed flare (cone) at each end that traps a mating collar axially. The pin is a solid of revolution, so an elevation and a plan describe it fully. All numbers below are generated from the chosen nominal set in doc/make_pin_html.py.

Valid range: 0 < p_ang < 90, rd > pd, h > 2·cone. With h = 10 the two complete-cone apexes coincide, since h = 2·ca.

Views

Clearance envelope

Starting from the nominal geometry, every surface is pushed out along its own outward normal by c = 0.1 mm; where two offset faces meet at the end rims they are extended to a sharp corner. The result is again a retained pin of the same flank angle, with h′ = h + 2c, pd′ = pd + 2c and rd′ = rd + 2c·cot(p_ang/2).

Area of rotation

The pin is swept by revolving the closed meridian profile about the z axis. The profile lies in the XZ half-plane (y = 0): x is the distance from the axis and z the height. The closing segment P5 → P0 lies on the axis, so a 360° revolution makes a closed solid. Every point is shown as an equation below.

The envelope is built from z = 0 like any pin. To centre it on the nominal pin, as in the drawing, shift it by −c (z → z − c), so it spans z = −0.10 … 10.10.

Module

The part is built by pin_retained() in pin_retained.py; the same call with clearance=0.10 gives the envelope. 

from pin_retained import pin_retained

pin = pin_retained(doc, "Pin", height=10.0, diam=6.0,
                   diam_end=10.0, angle=45)
env = pin_retained(doc, "Envelope", height=10.0, diam=6.0,
                   diam_end=10.0, angle=45,
                   clearance=0.10)

Values: pd = 6.0, rd = 10.0, h = 10.0, p_ang = 45, c = 0.10. Generated by doc/make_pin_html.py; regenerate after changing a parameter.
