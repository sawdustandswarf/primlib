Sleeve

The sleeve is the hollow barrel that rides a retained pin. Its exterior is a cylinder capped by 45° cone flanks meeting at a sharp ridge ring; its bore is the retained pin grown by a running clearance. Two stacked sleeves touch only along the ridge ring, so a column closes cleanly. It is a solid of revolution, so an elevation, a plan and a fit section describe it fully. Area of rotation

The sleeve is the region between two meridian paths, revolved about the z axis. Both lie in the XZ half-plane (y = 0): x is the distance from the axis, z the height. Nothing touches the axis, so the revolved solid is hollow.

The part is built by sleeve() in sleeve.py, which imports pin_retained() from the same library to cut the bore.

from sleeve import sleeve

The solid-of-revolution route mirrors the pin's: profile_points() returns the six wire vertices, profile_sketch() builds the sketch and sleeve_revolved() revolves it. The internal void is exactly pin_retained(doc, ..., h, pd + 2·tol, rd + 2·tol).

Values: pd = 6.0, rd = 10.0, h = 10.0, kd = 13.0, tol = 0.10. Generated by doc/make_sleeve_html.py; regenerate after changing a parameter.
