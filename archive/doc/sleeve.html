Sleeve

The sleeve is the barrel that rides a retained pin (pin_retained.py in this library): a hollow solid of revolution — an exterior cylinder capped by 45° cone flanks that meet at a sharp ridge ring, around a bore that is the retained pin grown by a running clearance. Two stacked sleeves touch only along the ridge ring — they kiss at a ring — so a column of them closes cleanly. A solid of revolution is fully described by an elevation and a plan; the bore needs the fit section on the second sheet.

This page is the single source of truth for the sleeve. The part lives in the parts library fc_lib as the module sleeve.py, alongside its mating part pin_retained.py; other notes point here rather than duplicate it.

Module

The part is built by sleeve() in fc_lib/sleeve.py. The module imports pin_retained() from the same library to cut the internal void, so the two files belong together. The signature: 

def sleeve(doc, name, height, diam, diam_end,
           diam_outer=13.0, tolerance=0.1, ridge_radius=None):
    """Hollow sleeve exactly `height` tall, riding a retained pin.
    `diam_outer` is the sleeve's outside diameter; `tolerance` the
    running clearance over the pin. `ridge_radius` defaults to the
    midpoint between the bore flare and the outer wall so the contact
    ring clears the pin cut."""

Typical use from a script or the FreeCAD Python console: 

import sys
sys.path.insert(0, "<path to>/fc_lib")
import FreeCAD as App
from sleeve import sleeve

doc = App.newDocument()
sk = sleeve(doc, "Sleeve", height=10.0, diam=6.0, diam_end=10.0)
doc.recompute()

The module also offers a solid-of-revolution route through profile_points(), profile_sketch() and sleeve_revolved(), which builds the sleeve as a sketched meridian profile revolved about the z axis — see Method 2 under Construction.

Run the module directly (freecadcmd sleeve.py) to build an inspection model: one retained pin plus one sleeve sliced down the centre axis.

Construction

The sleeve is a solid of revolution, and there are two equivalent ways to build it as booleans. The model uses the first (boolean cut tools); the second (revolve of the meridian profile) gives the identical solid and is often easier to reason about — and is implemented directly by sleeve_revolved() (see Method 2 below).

Method 1 — end-face cut tools (as modelled)

The barrel starts as a plain cylinder of diameter kd, exactly one sleeve tall. Two cut tools, one per end, remove everything on the wrong side of each end face; the finished faces then read z = |r − a| at the bottom and z = h − |r − a| at the top.

  1. Bottom core cone — radius a at z = 0 tapering to its apex at z = a (r = a − z): removes the deep valley around the axis.
  2. Bottom rim wedge — the band a + z < r < kd/2 of height fl, built as a cylinder minus a cone (r = a + z): removes the outer slope down to the rim.
  3. Bottom tool — their union, subtracted from the body. The top tool is the same pair mirrored about z = h/2.
  4. The toleranced pin — pin_retained() grown by tol on every face — subtracted last, leaving the bore.

Subtracting the whole toleranced pin is safe: near the end faces its flares lie inside the valleys the cut tools have already opened, so only its throat cylinder does any cutting. The bore the sleeve presents is therefore the valley cones opening into the throat; the pin’s flares ride in the valleys with a radial gap of exactly fl = kd/2 − a (the two 45° cones are parallel).

Method 2 — revolve of the meridian profile

The same solid is the revolution of its meridian cross-section about the z axis: the region between the outer profile (the W / inverted-W capped cylinder) and the bore profile (the valley cones plus the throat cylinder). The module builds this route directly: 

profile_points(height, diam, diam_end,
               diam_outer=13.0, tolerance=0.1, ridge_radius=None)
    -> the six profile vertices Q0..Q5 as App.Vector (x, 0, z)

profile_sketch(doc, name, height, diam, diam_end,
               diam_outer=13.0, tolerance=0.1, ridge_radius=None)
    -> the profile as a Sketcher sketch in the XZ plane

sleeve_revolved(doc, name, height, diam, diam_end,
                diam_outer=13.0, tolerance=0.1, ridge_radius=None)
    -> the same sleeve as a Part::Revolution about the z axis

Vertices are (x, y, z) with y = 0 throughout, in path order (closing Q5 → Q0 along the bottom valley cone): 

Q0 = (ridge,      0, 0             )   bottom valley apex (bore vee)
Q1 = (outer_rad,  0, rim_h         )   bottom flank -> outer wall
Q2 = (outer_rad,  0, h − rim_h     )   outer wall -> top flank
Q3 = (ridge,      0, h             )   top flank -> top valley apex
Q4 = (throat_rad, 0, h − valley_z  )   top valley cone -> throat
Q5 = (throat_rad, 0, valley_z      )   throat -> bottom valley cone

where valley_z = ridge − throat_rad. The bore is therefore the two 45° valley cones (r = ridge − z at the bottom, r = ridge − (h − z) at the top) opening into the throat cylinder — exactly the surfaces the cut tools leave, not the pin profile. Nothing touches the axis, so the revolved solid is hollow.

When 2·a > h — true for the defaults on this page: 2a = 11.6 mm vs h = 10 mm — the two valley cones overlap through the middle and the meridian region is self-intersecting there; the revolve is taken over the part where the profile is well-ordered, which is exactly what the boolean model produces.

a (ridge_radius) is the real parameter: it sets the ring stacked sleeves kiss on, the flank height fl = kd/2 − a, and how far the valley cones reach into the height. The default (flare_rad + outer_rad)/2 places it midway between the bore flare and the outer wall so the ring clears the pin cut.

Valid range: a > flare_rad (the contact ring must clear the bore), a ≤ outer_rad (the ridge cannot stick out past the wall), outer_rad − a < h/2 (the W flanks must fit in the height) and h > 2·c_b (the bore flares must fit). Outside that range sleeve() reports an error and builds nothing.

Primitives used by sleeve()

The function builds the sleeve from fifteen Part objects: a body, two mirrored cut tools of five objects each, two profile cuts, the toleranced pin (built by the library’s own pin_retained()) and the final cut. The construction objects are hidden once the cuts are made. The names below use name for the argument passed to sleeve().

Only two primitive kinds are needed — a cylinder (Part::Cylinder) and a cone (Part::Cone) — plus cuts and one Part::MultiFuse per end; the bore comes from pin_retained(clearance=tol).

Views

First-angle projection, delivered as two separate drawings: a front view (elevation, perpendicular to the pin axis) and a top view (plan, looking down the pin axis).

Reading the views

  • Solid outline — visible edges: the W bottom face, the inverted-W top face and the cylindrical wall between them.
  • The sharp corners at (±a, 0) and (±a, h) — the valley and ridge rings where each 45° pair of flanks meets; the plan shows the ridge ring as the Ø11.6 circle. Stacked sleeves touch only along that ring.
  • Dashed — the bore: the valley cones (r = a − z) opening into the throat cylinder. The toleranced pin’s flares never reach the sleeve wall, so they add no edges.
  • The throat Ø(pd + 2·tol) is what retains the sleeve on the pin: the pin’s flare (Ø(rd + 2·tol) with clearance) cannot pass it.

Sleeve on the pin — fit section

The bore is cut by subtracting the retained pin grown by tol on every face — pin_retained(clearance=tol) — so the fit is exact by construction.
